# WQC Bike Share Redistribution Project 🚲⚛️

Welcome to the official repository for the **Western Quantum Club (WQC) Bike Share Redistribution Project**.

## Overview

This project explores how quantum and classical optimization techniques can be applied to improve **bike-share redistribution** for our clinet **Bike Share Toronto**. The problem we're addressing is how to efficiently rebalance bikes between stations to meet demand and minimize operational costs.

Our goal is to build a proof-of-concept solution that models Bike Share Toronto's bike network and applies quantum-enhanced optimization techniques to generate efficient redistribution routes.

## 🚀 Goals

- Model Western University's bike share system as a graph.
- Identify imbalances in bike station inventory (surplus/deficit).
- Formulate redistribution as an optimization problem.
- Compare classical vs quantum optimization approaches.
- Evaluate solution quality, scalability, and feasibility.

## 🧠 Technologies Used

- Python
- D-Wave Ocean SDK (quantum modeling)
- NumPy / SciPy
- Matplotlib / Seaborn (for visualizations)
- Jupyter Notebooks
